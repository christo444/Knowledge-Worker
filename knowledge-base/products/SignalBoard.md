# Product Summary

# SignalBoard: Service Insights

## Summary

SignalBoard helps managers understand service performance across multiple
teams. It gathers operational events and presents trends without exposing
private message content.

## Features

- **Trend Dashboards**: Compare volume, backlog, and response time by period.
- **Custom Metrics**: Define metrics for different teams and service lines.
- **Scheduled Reports**: Send summaries to approved recipients each Monday.
- **Threshold Alerts**: Notify managers when agreed service targets are missed.
- **Role-Based Access**: Restrict financial and customer-level details.

## Plans

SignalBoard is available as an add-on to OrbitDesk Business and Enterprise
plans. Setup includes a two-week configuration workshop and one administrator
training session.

## Roadmap

Upcoming work includes anomaly detection for unusual workload changes and a
read-only auditor role.
